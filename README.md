# Data Science Fundamentals Assessment

Complete technical submission for the Data Science Fundamentals Assessment.

## Coverage
- Data Science lifecycle
- Descriptive, diagnostic, predictive and prescriptive analysis
- Real-world applications
- Python variables, data types and operators
- Conditions, loops and functions
- Lists, tuples, dictionaries and sets
- File handling
- Mean, median, mode
- Variance and standard deviation
- Percentiles and probability
- Correlation
- Numerical, categorical, ordinal, datetime and text data
- Data cleaning and manipulation
- Exploratory Data Analysis and visualization
- Clean coding and documentation
- Reproducibility
- Responsible interpretation

## Run the Project
```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Install:
```bash
pip install -r requirements.txt
```

Launch:
```bash
jupyter notebook
```

Then open `Data_Science_Fundamentals_Assessment.ipynb` and run all cells.

## Dataset
The EDA section uses reproducible synthetic data and does not require an external download.

NumPy random seed `42` is used for the synthetic EDA dataset.
